# Home "Soluções para Alugar no ABC" — Plano de Implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construir a Home da Gastaldo Seguros em Astro estático, com estrutura de layout inspirada na página "Soluções para Alugar" da Porto e identidade visual da Gastaldo, focada em SEO local e performance.

**Architecture:** Uma página (`src/pages/index.astro`) composta por componentes `.astro` de seção. Os dados (contato, soluções, benefícios, imobiliárias, cidades) ficam em `src/data/*.ts`. CSS global com tokens em `src/styles/`, CSS de cada componente no `<style>` do próprio componente, e JS nativo mínimo só para abas, menu mobile, setas do carrossel e mapa.

**Tech Stack:** Astro 7 (static), CSS puro, JS nativo, Poppins woff2 local (copiada de `@fontsource/poppins`, devDependency), testes com `node --test` sobre o HTML gerado em `dist/`.

**Spec:** `docs/superpowers/specs/2026-11-04-home-design.md`. O texto exato da página vem do PDF `C:\Users\João Vitor\Downloads\Página Home – Garantias Locatícias no ABC.pdf`, que é a fonte da verdade da cópia e dos níveis H1/H2/H3.

## Global Constraints

- Sem React/Vue/Svelte/Tailwind/jQuery/biblioteca de carrossel. Nenhuma integração em `astro.config.mjs` além do padrão.
- Fundo do site branco (`#FFFFFF`).
- Poppins local, pesos 300/400/500/600/700, subset latin, `font-display: swap`, preload só do woff2 do peso 700.
- Tokens de cor exatamente como na tabela do spec (`--marinho #043967`, `--marinho-profundo #0B2550`, `--azul #1A7DF0`, `--azul-escuro #0A6FD6`, `--azul-claro #6CB8FF`, `--azul-ceu #A8DBFF`, `--azul-vivo #1FB0FF`, `--amarelo #FFC53D`, `--cinza-fundo #F4F7FB`, `--texto #1B2A3A`).
- Logo: `public/brand/logo-gastaldo.svg` (fundo claro) e `public/brand/logo-gastaldo-branco.svg` (fundo escuro). Já existem.
- Fotos: nenhuma foto real nesta entrega; todas usam `<ImagemReservada>`.
- Todo dado `[entre colchetes]` do PDF aparece via `<Pendente>` e nunca é inventado.
- Cópia em pt-BR, idêntica ao PDF; comentários de código em pt-BR.
- Exatamente um `<h1>` na página; os H2/H3 seguem os marcadores do PDF.
- Mensagem do WhatsApp flutuante: `Olá! Quero saber sobre as soluções para alugar.`
- JS total enviado ao cliente: ≤ 5 KB (sem minificar).

## Review Focus

1. **Sem JavaScript**: as três listas de benefícios e todos os cards precisam estar visíveis e legíveis (teste: no HTML estático nenhum `[role=tabpanel]` tem `hidden`; o JS é que esconde).
2. **Celular de 360 px**: nenhuma rolagem horizontal da página, mesmo com o carrossel (verificação manual na Task 8).
3. **Teclado**: abas navegáveis por setas e Tab, foco visível em botões e links, e o carrossel rolável por teclado (teste de atributos ARIA na Task 5; verificação manual na Task 8).
4. **Links de WhatsApp com acentos e número pendente**: URL `https://wa.me/<número>?text=<encodeURIComponent>` sempre válida, com acentos codificados (teste na Task 2).
5. **`prefers-reduced-motion`**: sem rolagem suave nem transições quando o usuário pede menos movimento (teste: o CSS gerado contém a media query; Task 1).
